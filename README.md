# PunanovStore · КР №4

Интерактивный интернет-магазин на чистом JavaScript. Основа — [адаптивная версия PunanovStore из КР №3](https://github.com/punan532/kr3-responsive-shop), продолжение [исходного магазина КР №1](https://github.com/punan532/kr1-html-css-shop). Тема работы — DOM, события, формы и валидация.

Пунанов Егор Андреевич, ЭФБО-06-25.

[Открыть магазин на GitHub Pages](https://punan532.github.io/kr4-js-shop/)

## Запуск

В папке проекта выполните `python3 -m http.server 8000` и откройте [главную страницу](http://localhost:8000/). Для сравнения двух работ на одном сервере откройте каждую из своей папки. Сборка и библиотеки для запуска не нужны.

## Страницы

| Страница | Что можно сделать |
| --- | --- |
| `index.html` | Посмотреть популярные товары и оформить быструю заявку в диалоге |
| `catalog.html` | Найти товар, сравнить цены и добавить выбранный вариант в корзину |
| `product.html?id=4` | Посмотреть пример карточки с составом упаковки, ценой и доступностью |
| `cart.html` | Изменить количество, удалить позицию, проверить скидку и итог |
| `order.html` | Подготовить заявку на отдельный товар или всю корзину |
| `contacts.html` | Посмотреть контакты и заполнить форму обратной связи |

Общие стили лежат в `css/style.css`, адаптивные правила — в `css/responsive.css`. В `images/` находятся исходные фотографии и варианты WebP. В `lighthouse/` сохранены отчёты для адаптивной основы КР №3.

## JavaScript

| Файл в папке js | Назначение |
| --- | --- |
| `data.js` | Восемь объектов товаров, форматирование рублей и создание DOM-элементов |
| `catalog.js` | Генерация карточек, совместная обработка поиска, категории и порядка сортировки |
| `product.js` | Выбор товара по адресу страницы, вывод характеристик и обработка неизвестного идентификатора |
| `cart.js` | Добавление, изменение количества, удаление, счётчик, скидка и сохранение корзины |
| `validation.js` | Проверка полей, связь ошибок с полями, сумма выбранной заявки и подтверждение |
| `modal.js` | Быстрый заказ из карточки на главной и закрытие диалога |
| `main.js` | Управление мобильным меню и фокусом |

У каждого товара есть уникальный числовой `id`, название `title`, категория `category`, числовая цена `price` и признак наличия `isAvailable`. Дополнительные поля содержат единицу заказа, описание, имя файла фотографии и альтернативный текст. Наборы с разным количеством единиц имеют отдельные цены.

## Каталог и безопасный вывод

Поиск реагирует на `input`, удаляет пробелы по краям и сравнивает фрагмент названия без учёта регистра. Категории получаются из массива товаров. При `change` выбранная категория и сортировка применяются к текущему запросу. Метод `filter` возвращает новый массив, поэтому сортировка по возрастанию цены, убыванию цены или русскому алфавиту сохраняет исходный порядок в `products`.

После отбора обновляются счётчик и карточки. Если совпадений нет, кнопка «Показать все товары» сбрасывает условия и возвращает фокус в поиск. Недоступную позицию можно открыть и изучить, кнопка добавления для неё отключена.

Контейнеры находятся через `querySelector`. Карточки собираются через `createElement`, `classList` и `append`. Текст из данных и полей формы выводится через `textContent`. Для перерисовки списка используется `replaceChildren`. Обработчики `click`, `input`, `change` и `submit` подключены через `addEventListener`.

## Корзина и оформление

Для каждой позиции корзина хранит в `localStorage` только идентификатор и количество. При чтении проверяются структура, наличие товара и допустимое количество от 1 до 99. Стоимость берётся из каталога. Событие `storage` обновляет корзину в других вкладках.

Счётчик и стоимость вычисляются через `reduce`. При покупке от трёх единиц действует скидка 5% на всю корзину, округлённая до копейки. Цена набора считается за одну упаковку. Страница заявки показывает тот же итог.

Форма проверяет имя, почту, российский номер телефона и согласие. Разрешены пробелы, скобки и дефисы в номере. Под каждым ошибочным полем появляется подсказка, связанная через `aria-describedby`, фокус переходит к первой ошибке. После успешного ввода форма очищается и выводит подтверждение с именем, товаром и суммой. Это имитация оформления в браузере. Контактные данные в хранилище не записываются.

## Как проверить

1. В каталоге введите «бутер» и выберите «Еда». Останутся четыре позиции. Переключите порядок цен.
2. С тем же запросом выберите «Напитки». Появится пустое состояние. Нажмите «Показать все товары», чтобы увидеть восемь позиций.
3. Добавьте три обычных бутерброда по 121 ₽. Стоимость до скидки составит 363 ₽, скидка — 18,15 ₽, итог — 344,85 ₽.
4. Обновите страницу корзины. Перейдите к заявке и сверьте итог. Отправьте пустую форму, затем заполните её и проверьте подтверждение.
5. Вернитесь в корзину и уменьшите количество до двух. Скидка исчезнет, итог изменится на 242 ₽. Удалите последнюю строку и перейдите в каталог из пустой корзины.
6. На главной откройте «Быстрый заказ» для бычка. Проверьте выбранный товар и закройте диалог клавишей Escape.
